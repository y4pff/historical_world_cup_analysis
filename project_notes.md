3. Exploratory Data Analysis

Before jumping into insights, we ask:

How many matches are in the dataset?
How many tournaments?
Which years?
Missing values?
Duplicate matches?

This is something interviewers love because it shows you don't assume the data is perfect.

4. Performance Analysis

This is the main part.

We'll answer around 12–15 questions.

For example:

Teams
Which countries have played the most World Cup matches?
Which countries have won the most matches?
Highest win percentage?
Most goals scored?
Best goal difference?
Tournaments
Highest scoring World Cup?
Lowest scoring?
Average goals per game?
Highest attendance?
England
England's overall record
England's goals
England by tournament
England knockout performance
5. Conclusions

"What did we learn?"

Not just numbers.

Actual insights.

For example:

Brazil's longevity and consistent qualification make them one of the most successful nations rather than simply their number of trophies.
